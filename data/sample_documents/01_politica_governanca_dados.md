# Política de Governança de Dados para IA

Esta política define critérios para uso de dados corporativos em Analytics, Machine Learning e GenAI.
Dados classificados como sensíveis devem ter controle de acesso, mascaramento e auditoria antes de serem usados em aplicações inteligentes.
Todo produto de dados deve possuir owner, domínio, descrição, classificação, regras de qualidade e linhagem.
Para casos de RAG, os documentos devem manter metadados de origem, versão, data de vigência e nível de sensibilidade.
Respostas geradas por IA devem registrar pergunta, documentos recuperados, score de similaridade, latência e status da resposta.
