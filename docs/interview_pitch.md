# Pitch para entrevista

Desenvolvi um case de Engenharia de Dados para GenAI usando arquitetura Lakehouse. O fluxo ingere documentos, organiza em Bronze, Silver e Gold, aplica regras de qualidade, gera chunks e embeddings, cria uma busca semântica e expõe uma consulta RAG com fontes, score, auditoria e avaliação.

O objetivo foi mostrar que GenAI em empresa não começa pelo chatbot. Começa pela fundação de dados: qualidade, governança, rastreabilidade, segurança, versionamento, observabilidade e controle sobre quais dados alimentam as respostas.

Meu papel como Engenheiro de Dados é preparar essa base confiável para que Analytics, Machine Learning, IA e GenAI possam consumir dados com segurança e valor de negócio.
